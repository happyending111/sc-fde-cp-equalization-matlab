# SC-FDE CP长度对均衡性能影响 MATLAB仿真
本科毕设项目，搭建SC-FDE单载波频域均衡MATLAB仿真平台。
采用UW独特字序列实现定时同步，在莱斯多径信道下，研究不同CP长度对频域均衡效果的影响。

### 仿真内容
- QPSK调制，莱斯多径信道，引入载波频偏、相位偏移
- 输出：原始星座、信道畸变星座、频偏相偏畸变星座、UW定时同步图、同步后星座、均衡后星座
- 分析ISI、误码率与频谱效率之间的权衡

### 技术栈
MATLAB，SC-FDE，UW定时同步，莱斯信道，频域均衡

### 仓库内容
- src：仿真源码
- figures：全部星座图、定时同步仿真图
- docs：毕设摘要

本项目仅用于求职成果展示。
